# Product Guidelines

## Brand & Voice
- **Name:** DeterminaPass
- **Tone:** Technical, secure, direct, user-centric, and transparent.
- **Visuals:** Dark mode first (`#0f111a`), clean gradients (`#6366f1` / `#a78bfa`), high contrast, modern sans-serif typography.

## UX Principles
1. **Zero-Persistence Guarantee:** Never persist mnemonic passwords or generated passwords to disk or memory leaks.
2. **Real-Time Responsiveness:** Passwords recalculate as the user types without requiring manual "Generate" clicks.
3. **Public YAML Metadata:** File exports contain ONLY public metadata (site, user, date, security level).
